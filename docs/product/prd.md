# 在线简历编辑平台产品需求文档（PRD）

> 文档状态：讨论稿 0.6  
> 目标版本：1.0  
> 约定：标记为“待确认”的内容不属于正式需求，确认后再调整状态。

## 1. 产品概述

### 1.1 产品定位

面向所有求职者的免费在线简历编辑平台。平台帮助用户创建和管理多份简历，通过可视化编辑、模板切换、AI 内容优化、文件导出和短链接分享，完成从简历创建到投递或展示的完整闭环。

### 1.2 目标用户

- 所有有简历创建、维护、导出或分享需求的求职者。

### 1.3 产品形态

项目由三个应用组成：

1. 用户端 Web：落地页、账号体系、简历管理、简历编辑、导出与分享。
2. 管理端 Web：用户、模板和系统配置管理。
3. 服务端：向两个前端提供认证、数据存储、导出、分享和后台管理能力；AI Key存储在浏览器本地。

### 1.4 1.0 目标

- 优先快速完成“进入产品—创建简历—编辑—保存—导出或分享”的核心闭环。
- 1.0 同时具备用户管理、模板管理和系统配置三类管理端能力，不能因追求最小闭环而省略。
- 产品完全免费，1.0 不设计会员、付费模板或付费功能。

### 1.5 暂不纳入 1.0

- Google、GitHub 等第三方账号登录。
- 会员、订阅、订单、支付和付费模板。

## 2. 用户角色

| 角色     | 说明                 | 主要权限                                                   |
| -------- | -------------------- | ---------------------------------------------------------- |
| 游客     | 未登录的访问者       | 浏览落地页和模板、试用编辑器；不能保存到服务端、导出或分享 |
| 注册用户 | 使用邮箱登录的求职者 | 管理、编辑、自动保存、导出和分享自己的简历                 |
| 管理员   | 平台运营或维护人员   | 进入独立管理端，管理用户、模板和系统配置                   |

## 3. 账号与访问规则

### 3.1 用户认证

- 普通用户使用邮箱作为主要账号标识。
- 普通用户采用“邮箱 + 密码”注册和登录，并基于 Better Auth 实现认证。
- 注册时需要验证邮箱有效性。
- 支持退出登录和忘记密码后的邮件重置密码。
- 1.0 不提供邮箱验证码免密登录。
- 第三方登录列入后续规划，1.0 不开发。

### 3.2 管理员认证

- 管理员认证不使用 Better Auth。
- 管理端由项目自行实现独立 Session 鉴权。
- 管理员账号来源、Session 有效期和安全规则待确认。

### 3.3 游客试用

- 游客无需登录即可进入编辑器试用。
- 游客内容不保存到服务端。
- 系统向游客提供一份默认简历，游客只能编辑这一份简历。
- 游客草稿只保留一份，并通过前端 Zustand 状态持久化保存在浏览器本地。
- 游客登录成功后，将本地草稿同步至服务端并转为账号下的正式简历。
- 游客触发导出或分享时必须先登录。
- 登录用户的简历自动保存。

## 4. 用户端功能范围

### 4.1 首页落地页

- 产品价值和核心能力介绍。
- 编辑器或创建简历的主行动入口。
- 模板展示入口。
- 登录/注册入口。

### 4.2 多简历管理

- 用户可拥有和管理多份简历。
- 新建简历时必须先选择一个模板，不提供脱离模板的新建空白简历入口。
- 支持重命名、复制、删除、缩略图展示、按最近编辑时间展示和导入 JSON。
- 1.0 删除简历后立即物理删除，不提供回收站和恢复能力；执行前必须进行明确的二次确认。
- 1.0 默认不对用户展示固定的简历数量上限，但保留系统配置项，管理员可以调整上限。
- 达到上限后的交互和管理员调整上限后的存量数据规则待确认。

### 4.3 可视化简历编辑器

编辑器桌面端参照已确认的界面示例，采用“顶部操作栏 + 三栏工作区”的布局。

- 顶部操作栏：返回、简历名称、保存状态，以及导入、导出、分享等全局操作；具体操作集合随功能范围逐步确认。
- 左栏（模块管理）：分为“已使用模块”和“可添加模块”，展示模块名称和排序控制；用户可从此处定位、添加和管理模块。
- 中栏（内容编辑）：以卡片式表单纵向展示当前简历的模块，用户在表单中录入和修改内容。
- 右栏（实时预览）：以接近最终导出效果的纸张视图实时展示简历。

#### 4.3.1 简历模块

1. 个人信息。
2. 个人简介。
3. 工作经历。
4. 教育背景。
5. 技能特长。
6. 项目经历。
7. 资格证书。
8. 语言能力。
9. 自定义模块。

- 除自定义模块可添加多个外，其他模块在同一份简历中最多各存在一个。
- 工作经历、教育背景、项目经历、资格证书和语言能力等模块内部可包含多条记录。
- 支持拖拽调整模块顺序。
- 支持隐藏和重新显示模块。
- 支持删除模块，删除前需要二次确认；删除后可以从左栏重新添加。
- 个人信息模块不可删除，只能编辑。
- 工作经历、教育背景、项目经历、资格证书和语言能力模块内的多条记录支持新增、拖拽排序和删除。

#### 4.3.2 编辑与预览联动

- 点击左栏模块后，中间栏滚动至对应的编辑卡片。
- 用户在中间栏通过表单编辑内容，右栏实时更新预览。
- 右栏预览不高亮当前编辑模块，也不支持直接编辑文字，仅预览。

#### 4.3.3 撤销

- 1.0 编辑器必须支持撤销操作。
- 是否同时支持重做、可撤销的操作范围、历史步数和页面关闭后的历史保留规则待确认。

#### 4.3.4 自动保存

- 编辑器状态通过 Zustand 持久化至浏览器本地，作为游客草稿和登录用户编辑内容的本地兜底。
- 登录用户停止编辑 1 秒后触发服务端同步。
- 编辑器展示云端状态图标，用于反馈同步中、同步成功和同步失败状态。
- 断网或同步失败时，本地内容不受影响，云端图标显示同步失败；用户可以点击图标再次上传。
- 1.0 不要求恢复网络后自动重试，也不在存在未同步内容时阻止或提醒用户离开页面。

### 4.4 模板选择与切换

- 创建简历时可以选择模板。
- 编辑简历过程中可以切换模板。
- 切换模板原则上只改变展示样式，不丢失简历内容(表单字段全模版通用)。

### 4.5 AI 优化简历

- 支持通过 AI 优化简历内容。
- AI 配置由用户自行填写，包括 API Key 和 Base URL，并保存在用户浏览器前端。
- 1.0 服务端不保存用户 AI Key、不代理 AI 请求，也不统计 AI 用量；管理端因此不提供 AI 用量统计。
- 请求的时候需将key和url传给服务端，服务端来调用AI接口。

### 4.6 简历导出

- 支持导出 PDF。
- 支持导出图片，PNG格式。
- 支持导出本项目可再次使用的 JSON 数据。
- 游客导出前必须登录。

### 4.7 短链接分享

- 简历默认私有，不存在可公开访问的地址。
- 只有登录用户主动开启分享后，系统才为该简历生成可公开访问的短链接(可以设置有效期)。
- 用户可以随时删除短链接；删除后原短链接立即失效，简历恢复为仅本人可访问的私有状态。
- 游客分享前必须登录。

## 5. 管理端功能范围

### 5.1 用户管理

- 提供用户列表和用户详情查看。
- 支持搜索和筛选用户，具体筛选字段待确认。
- 管理员可以禁用和恢复用户账号。
- 管理员不允许修改用户信息，也不允许删除用户。
- 用户被禁用后，其现有 Session 立即失效，且不能重新登录。
- 禁用不删除用户及其简历数据。
- 用户被禁用期间，其已公开的简历短链暂停访问；管理员恢复账号后，原短链恢复访问。

### 5.2 模板管理

- 模板创建、编辑、预览、上下架和排序。
- 模板下架后不再显示在用户端的模板选择和模板更换列表中。
- 为防止现有简历损坏，已使用下架模板的简历仍保持原模板渲染；用户切换到其他模板后不能再选回已下架模板。

### 5.3 系统配置

- 管理可动态调整的系统配置。
- 候选配置包括站点信息、注册开关、简历数量限制。

### 5.4 管理首页概览

- 1.0 提供管理首页数据概览。
- 展示全站用户数量。
- 展示全站简历数量。

## 6. 服务端公共能力

- 用户认证与管理员 Session 鉴权。
- 用户、简历、模板、分享和系统配置数据持久化。
- 简历自动保存与并发更新冲突处理。
- AI 请求由服务端使用用户提供的配置发起，服务端不接入或记录 AI 用量。
- PDF 和图片导出任务处理。
- 短链接生成、解析和访问控制。
- 邮件发送。
- 参数校验、统一错误响应、日志和必要的安全防护。

## 7. 非功能要求

- 隐私：简历默认私有，只有用户主动开启分享后才可通过链接访问。
- 安全：密码安全存储、Session 安全、接口限流和防越权访问。
- 可靠性：自动保存失败可感知，避免编辑内容静默丢失。
- 兼容性：1.0 优先适配桌面端主流浏览器；手机端保留全部功能，通过简单的响应式布局进行适配，不为移动端单独裁剪功能。

3. 顶部操作栏最终包含哪些能力，预览缩放和编辑器定位联动方式。
4. AI 优化的作用范围、交互、兼容协议和浏览器本地密钥安全边界。
5. 模板的数据与渲染方式，以及切换模板时的内容兼容规则。
6. 导出格式、PDF 分页、图片格式与 JSON 版本兼容规则。
7. 分享链接的有效期、访问控制与隐私细节，以及系统配置的准确范围。
